## 🔍 Project Highlights

### 1. [Alumni Prospect Enrichment Pipeline](./alumni-prospect-research)

**Python · FastAPI · SQLAlchemy · SQLite · Web Scraping · AI/LLM Integration**

A production-style backend application that manages alumni records end-to-end - scraping and enriching prospect data, storing it in a relational database and exporting it in formats a sales or advancement team can act on (CRM-ready CSV, Excel, Power BI).

- Built a scraping and enrichment pipeline (BeautifulSoup) that collects and parses public prospect data, then validates and stores it via SQL.
- Built full CRUD + search/filter/pagination for alumni records, plus JWT-based authentication and role-protected endpoints.
- Designed analytics endpoints surfacing company- and city-level statistics for prospect segmentation.
- Added an AI-assisted research workflow (scrape → extract → parse → prompt → LLM) to auto-generate prospect profiles.
- Exported enriched data as CSV/Excel for direct CRM import and Power BI reporting and covered the codebase with automated tests (Pytest).
- 🔗 [Project README](./alumni-prospect-research/README.md)

### 2. [Superstore Sales & Profit Analysis](./Superstore-Business-Analysis)

**SQL · Microsoft Excel · Tableau**

An end-to-end retail analytics project on the Sample Superstore dataset - SQL for querying sales and profit, Excel for exploratory pivot-table analysis and a Tableau dashboard for executive-level reporting.

- Identified that **Technology** drove the highest sales while **Copiers** were the most profitable sub-category and that **Tables** and **Bookcases** consistently ran at a loss.
- Found that higher discounting was correlated with lower profitability and pinpointed **November** as the peak sales month.
- Delivered concrete recommendations: rebalance discounting on low-margin products, prioritize inventory for top performers and focus expansion on the highest-revenue states (California, New York).
- 🔗 [Live Tableau Dashboard](https://public.tableau.com/views/Superstore_Sales_Profit_Analysis_17766313435960/SuperstoreSalesProfitDashboard) · [Project README](./Superstore-Business-Analysis/README.md)
